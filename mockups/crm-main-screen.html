Registry-driven nav

The object list — counts, labels, order — renders from record_object rows created at import. Projects and Field Visits are the client's Salesforce custom objects (__c); nothing in this screen is hardcoded to a schema.

Chat-first writes

The Ask panel is scoped to the current view. The agent resolves the record by query, then proposes record_update — the approval card shows a field-level diff with a freshness check, and the affected row is flagged pending in the table. The activity log auto-fires because a rule allows it.

RBAC in the data, not the chrome

"My records" and row visibility come from GraphJin row policies on the viewer's JWT — the same enforcement the agent gets. The dashed avatar marks a record still owned by an unlinked SF user; it links automatically when j.keller first signs in via SSO.

Substrate status, quietly

The footer strip carries the operational story without stealing attention: migration provenance, delta-sync age, last verified backup, and outstanding identity work — each one click from its admin surface.
